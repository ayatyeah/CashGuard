## Пробелы (в открытых актах РК прямой нормы нет)
Еда/напитки; обязанность кассира блокировать экран; поведенческое требование держать дверь закрытой (есть только
требование к устройству — запираемая дверь); запрет посторонних в обычной операционной кассе (явный запрет — только для
кладовой/сейфовой комнаты и для касс обменных пунктов, D3 п. 41); передача денег третьим лицам; вход инкассатора в кассу.
Для них сервис должен писать «связанное требование» / «внутренние документы банка», а не выдавать норму за прямой запрет.
