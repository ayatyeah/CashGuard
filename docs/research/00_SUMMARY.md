# Сводка исследования (10 агентов) и план действий

Отчёты: `01`…`10_*.md` в этой папке. Ниже — что сошлось у нескольких агентов независимо, ранжировано по
(ожидаемый прирост баллов ÷ часы) с учётом нашей проверки: **любое изменение принимается, только если
leave-one-cabinet-out не падает** (сейчас 0.725 / 0 FP; финальная модель 0.825 / 0 FP).

## Главные выводы, подтверждённые ≥2 агентами
1. **Мелкие объекты не детектируются как объекты** (деньги 12–15 px, ключ 5–8 px). Решают: (а) последовательность
   действий рук (индустрия, #5 и #3), (б) состояние зоны как аномалия относительно нормы (#6), (в) кропы с увеличением
   и словарём ≤4 классов для open-vocab детекторов (#1). Не решают: классификаторы по 1–3 примерам (#6), VLM-2B (#2).
2. **Очередь жюри — риск нуля.** 5 видео разом при одном воркере → хвост не укладывается (#8, #9). Нужен постоянный
   сервер моделей (без перезагрузки весов на каждое видео) и совмещение этапов; цель ≤50 с на видео.
3. **Лицензии-ловушки** (сошлись #1, #3, #4, #6, #7): нельзя YOLO-World (GPL), YOLOE (AGPL), DINOv3 (кастомная Meta),
   Depth Anything V2 Base/Large (CC-BY-NC), Grounding DINO 1.5+/DINO-X (только облачный API), VideoMAE/TimeSformer/Hiera
   (NC), веса на NTU-RGB+D и Objects365 (некоммерческие датасеты), Gemma 3 / Llama 3.2 (свои условия), SMPL-X/BEDLAM (NC).
   Можно: OWLv2, Grounding DINO 1.0, Florence-2, DINOv2, SigLIP2, SAM 2, X-CLIP, MoGe-2, CLIPSeg, MobileSAM, Qwen3.5/Qwen3-VL.
4. **Нормативы у нас верные** (#10 сверил все 15 цитат), но есть сильные добавки: п. 22 (не покидать место при
   клиенте), п. 31 подп. 4) (выдача после пересчёта при клиенте — закрывает X-1), п. 24–25/42 (сумка), п. 45/59/61 (отбраковка).

3D-аватары/Unity/видео-диффузию, модели с NC-лицензиями.

- **Linux (я / Codex):** 2, 3, 4, 5, 7, 8 — всё на кэшированных кадрах, CPU.
- **Mac (Аслан):** 1 (сервер моделей, тест очереди), 6, 10 — по `docs/mac_18gb.md` + `09_mac_performance.md`.
- **Бэкенд (команда):** пути `/api/v1/...`, поле `file`, статусы, `DEMO_MODE=false` — `docs/api_contract_gap.md`.
- **Съёмка (команда):** `docs/shooting_plan.md` — единственный способ дать типам с 1 примером статистику.
