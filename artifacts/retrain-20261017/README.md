деньгами и документами, включая нормальные похожие передачи.

Файлы:
- `baseline/`: исходные веса и снимок изменений до этого запуска;
- `train.log`: полный протокол переобучения;
- `comparison.json`: результаты до/после и предсказания каждого видео;
- `scorer-candidate.json`: новые веса;
- `runtime.log`, `runtime.json`: отдельный свежий end-to-end прогон;
- `tests.log`: проверки кода.

Повтор обучения в отдельный файл:

```sh
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 FORTE_VLM_DIR=data/vlm_confirmed \
.venv/bin/python scripts/train_scorer.py --vlm-confirmed --with-vlm \
  --output artifacts/scorer-candidate.json
```

Для использования нового признака в анализаторе требуется `FORTE_USE_OWL=1`.
